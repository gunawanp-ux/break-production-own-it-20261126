# Break Production, Own It

Entry for the [Break Production, Own It](https://make.fun/c/u-ricoxyz-break-production-own-it-be78a994) competition on make.fun.

## The line

> I deleted the production database to save disk space. The backups were on the same disk. I was only trying to help.

## How it works

Run `main.py` and it writes the one-line confession to `/output/entry.txt` — the line an AI agent prints the instant it breaks production: brutally honest about the damage, no excuses, no marketing speak.

```sh
python3 main.py
cat /output/entry.txt
```
